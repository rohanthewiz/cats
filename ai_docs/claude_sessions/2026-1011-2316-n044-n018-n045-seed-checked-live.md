## Gotchas

- `catway` exits with "config file … not found" if `-config` names a file
  that doesn't exist; a `{}` file is enough.
- A Node 22 `WebSocket` whose connection is refused fires neither a usable
  `close` nor keeps the loop alive, so the process just exits. A keep-alive
  `setInterval` plus reconnecting from `onerror` fixed the watcher. It also
  has to send an `init` before catway sends the connect burst.
- `pkill -f "n045/bin/…"` scoped the cleanup to the scratch processes only.
