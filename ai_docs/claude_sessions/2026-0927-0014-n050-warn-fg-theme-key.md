## 1. The change

### The key

`warn-fg` is a new theme key: amber *text* on a panel. `--warn` stays the
colour for fills, edges and tints, where the hue is the signal.

- **Derivation:** `{"warn-fg", "warn", 0}` in `internal/theme/theme.go`, beside
  `err-fg`. The derivation diagram gains a `warn ─ todo · warn-fg` /
  `err ─ err-fg` line. The key is derived rather than required, so every other
  built-in theme and any sparse user theme is unchanged.
- **Why the three themes set a value rather than derive one:** a derivation
  can only copy a key or add alpha. Which way to move, darker or lighter,
  depends on the panel, not on `warn`.
- **Authored values**, the same hue as `warn` with lightness moved until the
  worst surface, the pill's 12% tint over the row's 7% tint, reaches at least
  4.8:1:

  | Theme | warn | warn-fg | row / pill / panel2 |
  |---|---|---|---|
  | solarized-light | `#b58900` | `#694f00` | 5.4 / 4.9 / 5.7 |
  | corporate | `#b07800` | `#734e00` | 5.6 / 5.0 / 6.0 |
  | solarized-dark | `#b58900` | `#f2b700` | 5.4 / 4.85 / 5.8 |
  | cats-green | `#e0b64e` | `#e0b64e` | unchanged |

  cats-green lists it only because `TestDefaultFullyAuthored` requires the
  default theme to set every key. `gofmt` realigned two of the new map lines.
- **Also added:** the `:root` fallback in `cmd/catway/web/css/01-theme.css`,
  and a row in the colour-key table of `docs/reference/configuration.md`. The
  settings modal lists keys from `Keys()`, so it needed no change.

### Where it's used

`cmd/catway/web/css/21-plugins.css` has three rules:

- `.row.plg .l2.warn`: the failed-default error line, and "couldn't check for
  updates" on installed rows.
- `.row.plg .pill.st.missing`: its text only. The border and tint stay
  `--warn`.
- `.plg-head .chk.warn`: the header's "update check failed".

### The test

`TestBuiltinWarnFgContrast` (`internal/theme/theme_test.go`) holds every
built-in's normalized `warn-fg` to 4.5:1 on `panel2`. It has a test-only WCAG
`contrastRatio` / `relLuminance` built on the package's `parseHex`. The floor
is `panel2` rather than the tinted rows so the test does not depend on CSS
percentages. The authored values aim above it to cover the tints.
