# Session: the heading paw opens a global todo pane (N-041)

Session ID: 2efe691d-b260-4603-b506-8070db1c672f
Date: 2026-09-26

This continues `2026-0926-2108-paw-click-opens-todo-pane`, which made each
workspace row's paw jump to its first todo pane and raised N-041 for the global
paw on the WORKSPACES heading. The user then asked: "do N-041 too".

## 1. What differs from a row's paw

- A row's paw has one workspace's panes to choose from. The heading's paw
  counts the **global** backlog, and every global manager (`todo: global (N)`
  or a bare `todo (N)`, see `isGlobalTodoTitle`) shows that same list from
  wherever it is open. `workspaceRollups` takes the max rather than the sum
  for this reason. So any global manager is a valid target, which leaves room
  to choose a good one.
- The lock can't refuse the whole click the way a row's lock does. The lock
  stops switching to *that* workspace, not reaching the global list.
- The heading (`#sec-workspaces > h2`, built in `sidebar.go`) has no press
  gesture of its own, and the fold pair in `.hctl` is a sibling of
  `#ws-global-todo`, not an ancestor. So unlike the row paw, there is no
  propagation to stop.

## 2. The change (cats `4117bba`)

`cmd/catway/web/js/07-workspaces.js`: new `gotoGlobalTodoPane()`. It works
from the live `paneInv`, looked up at click time:

1. It considers only panes whose title is global and still shows an open
   count.
2. It skips managers in locked workspaces, remembering the first locked
   workspace it saw.
3. It prefers a manager in the workspace this window is viewing
   (`layoutMsg.workspaces[].active`), because the jump then only changes
   focus or tab and doesn't switch workspace.
4. Otherwise it takes the first match in inventory order.
5. If every global manager is locked, it shows the toast
   `<ws> is locked — unlock it to reach the global todos`.

It reveals the chosen pane with `agent.focus`, as the row paws and the
PANES/AGENTS lists do.

In `renderWorkspaces`, the heading's paw gets the class `jump`, a tooltip
suffix "— click to open the todo pane", and
`pressActivate(gmark, gotoGlobalTodoPane)`.

`css/07-workspaces.css`: the pointer-cursor rule now also covers
`#ws-global-todo .todo-mark.jump`, and its comment covers both paws.
